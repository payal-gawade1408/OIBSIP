# PyBot — Python Chatbot

Beginner-friendly GUI chatbot made with Python and Tkinter.

## Features
- Chat window with message history
- Replies to greetings, help, name, time, date, Python, thanks, jokes, and goodbye
- Enter key sends a message
- Clear button
- No API key or third-party package required

## Run
Open Command Prompt in this folder and run:
```cmd
python chatbot.py
```
If Python is not recognized, try:
```cmd
py chatbot.py
```

## Example messages
`hello`, `what is your name`, `what time is it`, `what is today's date`, `tell me about Python`, `tell me a joke`, `help`, `bye`.

## How it works
This is a rule-based chatbot: it matches keywords and returns prepared replies. It does not use an online AI model.
