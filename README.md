# Python Task 3 — Random Password Generator

**Track:** Python Programming (Beginner-friendly GUI project)  
**Technology:** Python, Tkinter, `secrets`, `string`

## Features
- Password length control (minimum 8 characters)
- Uppercase, lowercase, numbers, and symbols selection
- Requires at least two character categories
- Uses Python's `secrets` module for secure random selection
- Guarantees at least one character from each selected category
- Optional exclusion of ambiguous characters (`0`, `O`, `1`, `l`, `I`)
- Strength label, copy button, generate-again button
- Shows the last five generated passwords in the current session only
- Passwords are not written to a file

## Requirements
Python 3.10+ recommended. Tkinter is included with many standard Python installations.

## Run
```bash
python password_generator.py
```
