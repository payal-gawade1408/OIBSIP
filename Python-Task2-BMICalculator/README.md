# BMI Calculator - OIBSIP Task 2
Intern: Payal Gawade

### Objective
Create a BMI calculator that takes weight and height.

### Features
- Takes weight (kg) and height (m)
- Formula: weight / (height^2)
- Classifies: Underweight, Normal, Overweight, Obese
- Shows BMI rounded to 2 decimals
- Validates wrong input

### How to Run
python PayalGawade_Task2.py
